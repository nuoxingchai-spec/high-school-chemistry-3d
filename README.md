# 高中化学方程式 3D 可视化

基于 Three.js 的高中化学交互演示平台：250 条方程式库、参数化 3D 实验台、实验室 / 化工厂双形态演示。无需构建、无外部 CDN 依赖，Three.js 已本地化在 `vendor/`。

## 功能

- **方程式库**：250 条高中化学方程式，9 大分类、标签、搜索、详情、复制与快捷键操作
- **实验室形态**：烧杯 / 集气瓶 / 坩埚 / 硬质玻璃管 / 水槽 / 电解槽 6 类装置，浓度与配比实时可调
- **化工厂形态**：任一实验均可一键切换为工业装置，按类型匹配 R-101 搅拌反应釜、T-201 气体吸收塔、F-301 高温焙烧炉、P-401 管式反应器、B-501 水解处理池、E-601 电解槽，含混凝土基座、管廊、阀门、控制柜、储罐与工段说明
- **默认工业形态**：从主页反应库或方程式库进入实验时，默认以化工厂形态打开，顶部小按钮可随时切换实验室 / 化工厂
- **化工厂全流程**：6 条重点方程式联动工业设备动画（硫酸稀释、铝热反应等）
- **危害与现象**：实时灾难/危害提示，实验现象、离子方程式与细节说明
- **反应库侧栏**：按重点程度排序，默认展示前 10 条，一键展开全部 250 条
- **浅蓝色日间主题**，OrbitControls 自由拖拽视角，移动端自适应取景


## 运行

无需安装依赖、无需构建：

- 双击 `start.bat`（默认 http://localhost:8000）
- 或手动启动本地服务：

```bash
python -m http.server 8010
```

然后访问 http://localhost:8010

## 目录结构

```
index.html        页面骨架与 UI
styles.css        全部样式（主题、面板、方程式库、实验台）
src/main.js       主控、UI 绑定、方程库/实验台调度
src/equations.js  250 条方程式数据
src/reactions.js  化工厂反应定义
src/plant.js      化工厂 3D 场景与设备
src/eqLab.js      参数化 3D 实验台引擎
src/eqDemoData.js 方程式 → 实验参数映射
vendor/three/     本地 Three.js r169（含 addons）
```

## 技术栈

Three.js r169（本地 vendor）+ 原生 ES Modules + import map，CanvasTexture / CSS2DRenderer / OrbitControls，WebGL 渲染。实验室与化工厂共享同一套反应体积与特效逻辑，切换时仅重建工业外壳、场景、灯光与镜头。

方程式库由 14 页手写化学讲义整理并校对。
